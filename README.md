# Student Management Portal

**Course:** 26CS102 – Foundation of Full Stack

**Project:** Student Management Portal

**Methodology:** Agile Scrum

## Project Description

The Student Management Portal is a web-based application designed to provide student information, course details, registration facilities, and contact information.

## Product Backlog

The Product Backlog is a prioritized list of features and requirements to be developed for the Student Management Portal.

| ID | User Story | Priority |
|---|---|---|
| US01 | As a user, I want to view the Home page to understand the portal. | High |
| US02 | As a user, I want to view the About page to learn about the institution. | Medium |
| US03 | As a student, I want to register by entering my personal details. | High |
| US04 | As a student, I want to view the available courses. | High |
| US05 | As a user, I want to view contact information. | Medium |
| US06 | As a user, I want to navigate easily between all pages. | High |
| US07 | As a developer, I want to maintain the project using GitHub. | High |

## Sprint 1 Plan

**Duration:** 1 week

**Sprint Goal:** To develop the basic static Student Management Portal using HTML5.

### Sprint Tasks

1. Create the GitHub repository.
2. Prepare the Product Backlog.
3. Create the Home page using HTML5.
4. Develop the About and Courses pages.
5. Develop the Student Registration and Contact pages.
6. Test the navigation links.
7. Commit and push the project files to GitHub.

### Expected Outcome

A static website containing five linked HTML pages with a consistent navigation menu.

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## Project Structure

- `index.html` – Home page
- `about.html` – About page
- `registration.html` – Student Registration page
- `courses.html` – Courses page
- `contact.html` – Contact page
- `styles.css` – Common styling
Conclusion

Agile Scrum practices help organize the development process into manageable tasks. GitHub is used to maintain source code, track changes, and manage project versions.
